# Beszel

Beszel has two components:

- **Server:** The dashboard that collects metrics and displays system statistics.
- **Agent:** Runs on each monitored machine and sends metrics to the server.

## Setup

1. Create a **System** in the Beszel dashboard to get the agent connection details.
2. Copy the generated **Public Key**, **Token**, and **Hub URL** into the agent configuration as required.
3. Start the agent and verify that the system appears in the dashboard.

Refer to the [Beszel documentation](https://beszel.dev/guide/what-is-beszel) for details.
